Pruthwiraj Patra — Personal Portfolio

A responsive personal portfolio website showcasing my academic journey, technical skills, projects, internship experience, certifications, and professional contact information.

About the Project

This portfolio is built from scratch using HTML5, CSS3, and JavaScript. It uses a dark professional visual style with white content and gold accents, with responsive layouts for desktop and mobile devices.

Internship and experience section

Design

The portfolio follows a 60 / 30 / 10 color balance:

60% Black/Dark tones — primary backgrounds and large surfaces

30% White — text and readable content

10% Gold — highlights, icons, borders, buttons, and interactive accents


Responsive Design

The website adapts to desktop, tablet, and mobile screen sizes.

On smaller screens:

Desktop navigation changes to a hamburger menu

The navigation closes after selecting a section

Education timeline cards adapt to the available width

Skill bars remain readable and responsive

Typography and spacing adjust for smaller displays


JavaScript Interactions

JavaScript provides lightweight interactions such as:

Mobile hamburger menu

Opening and closing the mobile navigation

Automatically closing the menu after selecting a navigation link

Updating the hamburger/close icon

Triggering skill-bar animations when the Skills section enters the viewport
