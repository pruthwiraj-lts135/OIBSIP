## 📖 How to Use

1. Open the OIBSIP repository on GitHub.


2. Open the index.html file located in the root directory.


3. Open the project hub through GitHub Pages.


4. The main index.html provides navigation to all three projects:

Landing Page 🌐

Portfolio / Profile 💼

Temperature Converter 🌡️



5. Select any project from the main page to open and explore it.


6. Each project remains inside its respective project folder, preserving the original repository structure.


7. The projects can also be run locally by downloading or cloning the repository and opening the relevant index.html file in a web browser.


8. The projects are designed to be responsive, allowing them to be viewed on both desktop and mobile devices. 📱
