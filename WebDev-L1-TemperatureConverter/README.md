# 🌡️ ThermoFlow – Smart Temperature Converter

A modern and responsive temperature converter built using HTML, CSS, and JavaScript. ThermoFlow provides instant temperature conversion between Celsius, Fahrenheit, and Kelvin with a clean Glassmorphism user interface.

---

## 📌 Features

- 🌡️ Convert temperatures between:
  - Celsius
  - Fahrenheit
  - Kelvin
- ⚡ Automatic conversion (No Convert button required)
- 🔄 Swap button to exchange units instantly
- 🎨 Modern Glassmorphism UI
- 🔥 Fire & Ice themed background
- 📱 Responsive design for different screen sizes
- ✅ Input validation for invalid or empty values
- 🔒 Read-only result field

---

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click **index.html** or open it using Live Server in VS Code.
4. Enter a temperature and enjoy instant conversion.
