# Landing Page

## 📌 Project Overview
This project is a responsive Landing Page developed as **Level 1 - Task 1** for the **Oasis Infobyte Web Development Internship**. It is designed using HTML and CSS with a modern, clean, and responsive layout.

## ✨ Features
- Responsive Navigation Bar
- Hero Section
- About Section
- Services Section
- Contact Section
- Footer
- Smooth Scrolling
- Hover Effects
- Card Animations

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Structure
```
WebDev-L1-LandingPage/
│── index.html

│── logo.png
└── README.md
```

## 🚀 How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser
